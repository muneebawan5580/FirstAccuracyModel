# First Accuracy Model

This project is a Machine Learning classification project based on the Breast Cancer dataset.

## 📌 Project Overview

The main purpose of this project is to analyze the dataset, preprocess the data, train Machine Learning models, and evaluate their performance using accuracy.

## 🔍 Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to understand the dataset and identify important patterns and relationships between the features.

The EDA process included:

* Understanding the dataset
* Checking data types
* Checking missing values
* Analyzing the target variable
* Exploring feature relationships
* Identifying patterns in the data

## 🧹 Data Preprocessing

Before training the models, the dataset was prepared for Machine Learning.

The preprocessing steps included:

* Handling unnecessary columns
* Preparing the target variable
* Splitting the data into training and testing sets
* Scaling features where required

## 🤖 Machine Learning

Different Machine Learning models were trained and evaluated to compare their performance.

The models were evaluated using:

* Accuracy Score
* Training and testing performance

## 📊 Model Evaluation

The main evaluation metric used in this project is **Accuracy**.

The accuracy score helps measure how many predictions were correctly classified by the model.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 📁 Project File

`FirstAccuracyModel.ipynb`

The Jupyter Notebook contains the complete process:

**EDA → Data Preprocessing → Model Training → Model Evaluation → Accuracy**

## 🎯 Learning Objective

This project was created to practice the complete Machine Learning workflow and understand how data analysis, preprocessing, model training, and evaluation work together.
